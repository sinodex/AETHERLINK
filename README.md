# AETHERLINK

> **Early-stage development. Building the bridge between devices.**

AETHERLINK is a cross-platform application project currently in early-stage development. The project is focused on creating a connected experience across Android, Apple platforms and Windows.

The first applications are already being developed. The Android app and the Windows app have been created and are continuing to evolve. The overall project direction, architecture and technology choices are still being refined during development.

## Project purpose

AETHERLINK is intended to act as a bridge for Windows and Linux devices that do not have built-in Bluetooth. The project is designed to make it possible for these devices to use the Bluetooth capabilities of a connected smartphone over USB.

The Windows application already exists and is being developed further. Linux support is planned, but Linux development has not started yet. The first Linux testing target is planned to be **Debian 13**.

## Current status

AETHERLINK is **not ready for a final release yet**.

The project is actively being worked on, tested and improved. Features, visual design, platform support and internal components may change before the first public release.

## Technology direction

AETHERLINK is still in an experimental development phase. One of the three core technology directions — **C, C# or C++** — may become part of the project as development continues. Additional languages or technologies may also be introduced, especially for the Windows application, if they are useful for the final architecture.

The technology stack is therefore not considered final at this stage.

## First release

The first public GitHub release is still being prepared. A release may arrive around **late 2027**, potentially around the middle of December, depending on development progress, testing and platform readiness.

This timeline is an estimate and may change.

## Testing

AETHERLINK is currently preparing its first beta version for Android and Windows. After this first Android/Windows beta has been released, people interested in testing the future iPhone app will be invited to register their interest.

People can already contact the creator via **Discord DM** if they would like to be considered for the future iPhone testing group or help with Linux support on distributions other than the planned Debian 13 target. The Discord link can be found in the creator's profile bio. Interested people may receive a confirmation, but they will not receive an iPhone app or test code at this stage.

The iPhone development itself is planned for after the first official release. The iPhone app and test access will only be provided when the relevant development and beta builds are ready. Linux development has not started yet, so Linux testing and development opportunities will become available later.

Early builds are experimental and may contain incomplete features, bugs or breaking changes. Tester feedback is highly appreciated and helps shape the future of AETHERLINK.
