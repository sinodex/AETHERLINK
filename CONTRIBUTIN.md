# Contributing to AETHERLINK

Thank you for your interest in AETHERLINK.

AETHERLINK is currently in **early-stage development**. The project is actively changing, so contributions, testing feedback and ideas are especially valuable during this phase.

## Ways to contribute

You can support the project in several ways:

- Test the first Android/Windows beta and register interest for future iPhone testing
- Help prepare or test future Linux support
- Report bugs and unexpected behaviour
- Share clear improvement suggestions
- Help identify platform-specific issues
- Review the user experience
- Discuss ideas for future features
- Contribute technical improvements when the project structure is ready for external contributions

## Testing early builds

Early builds are experimental and are not final releases. They may contain unfinished features, bugs, compatibility issues or changes that are not backwards compatible.

The first beta will be for Android and Windows. After that beta is released, people interested in testing the future iPhone app will be invited to register their interest. People can already contact the creator via **Discord DM** and may receive a confirmation, but no iPhone app or test code is available yet. iPhone development is planned for after the first official release. Linux development has not started yet. Linux support is planned to be tested first on Debian 13. If you would like to be considered for future iPhone testing, test another Linux distribution or help when Linux development begins, please contact the creator via **Discord DM**. The Discord link is available in the creator's profile bio.

When reporting a problem, please include:

- The platform you tested on
- The Linux distribution and version, if applicable
- The device or system type
- The approximate app version or build
- What you expected to happen
- What happened instead
- Clear steps to reproduce the problem, if possible

Screenshots or screen recordings may be helpful when describing visual or user-interface issues. Please do not share private information, credentials or personal data in an issue or message.

## Issues and feedback

Before opening a new issue, check whether a similar issue already exists. Use a clear title and describe one problem or suggestion at a time.

Good feedback is specific, respectful and easy to understand. Reports without enough information may be difficult to investigate.

## Pull requests

The project structure and technology direction are still being defined. Pull requests may not be accepted during every phase of early development.

Before starting a larger change, open an issue or contact the creator first. This helps avoid duplicated work and makes sure the proposed change fits the current direction of AETHERLINK.

If you submit a pull request:

- Keep the change focused
- Explain what was changed and why
- Avoid unrelated changes
- Mention which platform was tested
- Update relevant documentation when needed
- Do not include secrets, private credentials or generated build artifacts

## Technology direction

AETHERLINK is still evaluating its long-term technology direction. The project may use one of the three core languages — **C, C# or C++** — and additional technologies may be added later, especially for the Windows application.

Please avoid treating the current technology choices as final until the project reaches a more stable development stage.

## Code of conduct

Be respectful, patient and constructive. Personal attacks, harassment, spam and discriminatory behaviour are not welcome.

The goal of contribution is to improve AETHERLINK and create a helpful environment for developers and testers.

## Project stage

AETHERLINK is currently **Early Stage Development**. The first public GitHub release is still being prepared and may arrive around late 2027, potentially around the middle of December. This estimate can change as development and testing continue.
